Roadmap

Each phase starts only when the one before it is clean.

  1. 1

    Foundation and research

    Done

    Data importer, backtest engine and validation suite. The first four short-horizon strategies didn't qualify for paper trading; entry-level exchange fees set a high bar.

  2. 2

    D1, a pre-registered daily trend strategy

    Done

    Rules and gates were written before testing. It didn't pass all of them, so instead of tuning it, it runs unchanged as a forward test against frozen expectation bands.

  3. 3

    Paper operations

    Done

    Scheduled runs, Telegram briefings with strict privacy routing, a static read-only dashboard, security hardening, daily shadow checks against the backtest.

  4. 4

    Phase 3b · multi-strategy platform

    Next

    Reorganize so several strategies run side by side, each isolated from the others, then add multi-coin plumbing. Golden files prove D1 stays identical after every step.

  5. 5

    Phase 3c · the Censor

    Planned

    A scheduled, read-only Claude Code reviewer in its own repository, with cost tracking, plus a triage protocol where every finding needs a verdict backed by evidence.

  6. 6

    Phase 3d · simulated clock

    Planned

    Months of scheduled runs in minutes: month and year ends, daylight-saving switches, missed runs, restarts and exchange faults.

  7. 7

Read the workflow

Guardrails

  • Plan mode first; nothing changes before approval.
  • More than 70 numbered decisions with their reasoning.
  • Golden files must stay byte-identical through refactors.
  • Deploys stay outside run windows, with the journal backed up first.
  • Secrets scanned at every commit and push; exchange keys can't withdraw.
  • Account data only ever goes to a private chat.

Research discipline

  • Pre-registered rules and gates; holdout used once.
  • Every variant logged, so results are judged against the number of tries.
  • Estimates with intervals, never "statistically significant".
  • Deflated Sharpe Ratio and data-snooping tests for any new signal.
  • Paper trading tests the plumbing; proving an edge takes years.
