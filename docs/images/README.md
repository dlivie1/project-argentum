# Screenshots

Add images here and reference them from the README, e.g. `![Dashboard](docs/images/dashboard.png)`.

Suggested shots:

| File name | What to capture |
|---|---|
| `dashboard.png` | The main dashboard with `redact_amounts` turned on (percentages only) |
| `model-health.png` | The Model Health page, also redacted |
| `briefing-broadcast.png` | A daily briefing from the **broadcast group**, which by design contains no account data |
| `censor-report.png` | The top of a Censor report: the coverage table and the finding summary (after Phase 3c) |

Before adding any image, check it for:
- account amounts, balances, P&L in dollars, position sizes, tax figures;
- chat names, chat IDs, usernames, phone numbers;
- file paths that include your Windows username;
- browser tabs, bookmarks or the taskbar showing other personal things;
- anything in a terminal window behind the screenshot.

Crop tightly, or blur anything you aren't sure about.
